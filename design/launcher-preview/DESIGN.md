# KRKR-ns 游戏库：本地审核预览

这是原生启动器的视觉与交互参考。预览只使用内存中的 14 个虚构故事样本，不访问游戏目录，不保存设置，也不启动游戏程序。

直接打开 `KRKR-ns-launcher-review.html` 即可，无需服务器。源码为 `index.html`、`style.css`、`app.js`、`mock-art.js`；运行 `node package.mjs` 重新生成独立 HTML，猫耳logo和全部模拟CG均内联，无新依赖。URL 加 `?empty=1` 可直接查看空库，右上角省略号菜单也可切换审核状态。

顶栏标志为猫耳书本：浅紫封面、奶白内页、深紫细描边，右页一个克制的播放符号，不含标语。源文件`logo-artwork.svg`为56×56透明画布；`package.mjs`将其完整内联进独立HTML，并生成336×336的`logo-review.svg`大图。预览SVG画布位置(24,30)，大小56×56；通过内边距抵消保持品牌文字x88和其余header排版不变。原生推荐导出`logo-artwork.png`为56×56 RGBA，加载一次后绘制到(24,30)；图形实际中心约(52,57)，透明边距约6px，不需要圆角底板。

## 交互

- 上/下选择，可跨页；左/右翻页。鼠标或触控点击游戏只选中它。
- A 或 Enter 开始；B 或 Esc 返回；X 打开启动选项；Y 刷新。Switch 四键布局显示为上X、下B、左Y、右A。
- 主按钮或 footer 的“开始”单次确认才进入模拟启动画面；模拟画面明确标识为交互预览，B可返回。
- 启动选项与原生启动文件选择器对齐，提供虚拟`data.xp3`、`play.xp3`、`startup.tjs`、`start.tjs`四项；提示“通常无需更换，使用当前启动文件即可。”点击/A选择后返回游戏库，只在内存保留所选项。弹窗有焦点圈、Tab焦点约束、方向键选择、A确认和B返回。
- 左栏触控纵向滑动选择，横向滑动翻页。标准 Gamepad 按物理位置映射，方向键与左摇杆可导航。
- 选中条位移160ms；英雄插画透明度150ms、位移170ms。遵守系统`prefers-reduced-motion`。
- 页面加载后不弹窗、不自动启动、不打开新窗口。

## 图片设置

默认大图仍是纸片+初字，默认列表头像仍是初字。正常切换游戏不扫描图片。打开“图片”后，预览模拟解析六张本地SVG候选（校园、海岸、窗边、树林、两张角色插画），显示“模拟扫描”进度并明确不访问真实游戏内容。第一项仅标记推荐，不自动应用任何图。

两种用途分别保存草稿及已应用状态：`preview`为右侧860×358大图，`avatar`为51×51列表头像。切换用途保留各自草稿，点击候选不改变主屏；A或应用按钮只提交当前用途并返回主屏，B/Esc关闭并丢弃全部未应用草稿。每个游戏的数据独立，切换游戏保留内存设置。恢复默认只立即恢复当前用途，另一用途不变；恢复后应用按钮暂时禁用，重新选择候选可再次应用。

“从本地选择”使用仅接受PNG/JPEG的文件选择器，实际解码通过后将浏览器`blob:` URL加入当前游戏候选，只在页面内存中使用，不写文件/配置，不上传、不联网。图像显示为居中裁剪并保持比例。解码失败或格式不支持不会替换已应用图像。

图片面板上/下移动一行（三列），左/右移动一项；A应用当前候选，B返回，Y重新模拟扫描。L/R切换大图/头像，键盘可用Q/E；主屏Minus或I进入图片面板。Tab可访问上传、重置和关闭等操作，焦点保留在弹窗内。A对选项按钮执行对应操作，对图片候选则应用；所有图片设置操作都不会启动游戏。

| ID / 属性 | 用途 |

JS状态结构位于`app.js`内：`state.imageSettings[gameIndex] = { preview: asset|null, avatar: asset|null, candidates: asset[] }`，`state.imageDraft = { preview: assetId|null, avatar: assetId|null }`；`imageGame`锁定当前编辑游戏，`imageRole`为活动用途。资源`asset = { id, name, kind: mock|local, url }`。打开面板可预选当前图或第一候选，但只有应用操作提交；恢复默认清空当前role的资源引用。预览后端是内联SVG/内存URL，原生应接独立解析后端，不能把模拟扫描当作真实XP3读取。

### 验证

本目录保留可编辑的设计源码，`node package.mjs`可以重新生成独立HTML预览。审核截图、测试脚本与临时导出文件已经清理，不随程序发布。网页预览使用模拟候选，实际启动器实现位于`krkrsdl2/data/startup.tjs`。

原生启动器在用户打开图片面板后扫描散图和标准XP3索引；自定义图片目录为`sdmc:/switch/KRKR-ns/Artwork/`。预览图与头像分别生成PNG副本，配置保存在`launcher-artwork/`，普通游戏切换只使用元数据和启动器缓存。图片页码为整数；专用解码、损坏或过大图片显示失败原因，不能覆盖已应用图片。

原生面板中A应用、B返回、X切换用途、Y切换来源、L/R翻页。已通过168项原生UI检查、5项冷启动配置检查及20项图片解码和边界检查；临时测试源码及测试包按用户要求清理。当前版本经用户界面操作验收，Switch真机表现仍以设备测试为准。
